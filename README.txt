La página está hecha principalmente con HTML y CSS, y también use Bootstrap para 
hacer cosas como los carruseles de los juegos.La página principal muestra una presentación personal
donde podes descargar un cv de relleno, y una sección donde aparecen algunos de mis proyectos. 
Los proyectos que se muestran son Juego del Calamar, Mapi y Pokemon Terminal. 
Cada proyecto tiene su propia página y desde la página principal se puede entrar a ellas haciendo clic sobre las imágenes.
La pagina de cada juego tiene el mismo formato con el carrusel a la izquierda, y el titulo con su descripcion de cada juego
Abajo de este hay un link al repositorio.
El archivo background.css se encarga de controlar el aspecto visual de las páginas. 
En él se encuentran los colores, tamaños de letras, fondos, bordes, espacios, botones, imágenes y diferentes efectos. 
Los botones y las imágenes también tienen efectos cuando se pasa el mouse por encima para que la página sea más interactiva.
En teoria la pagina se adapta a los celulares al ser fluid la mayoria de las boxes, no esta comprobado.
El proyecto está dividido en diferentes archivos. El archivo index.html es la página principal, jdc.html, mapi.html y pkmn.html Son cada proyecto.
